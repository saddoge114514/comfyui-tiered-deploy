# aria2c 下载清单模板（models.example.txt）
#
# 用法：
#   aria2c -i models.example.txt -x16 -s16 -k1M --file-allocation=none ^
#          -c --auto-file-renaming=false --max-tries=15 --retry-wait=5
#
# 语法：一行 URL，紧跟缩进的 out=（文件名）和 dir=（落盘目录）
#
# 【重要】下载完必须做 sha256 校验，别信文件大小。
#   已实测的坑：aria2 预分配会留下全零空洞，文件大小、safetensors 头、
#   逐张量方差检查全部"正常"，只有哈希能发现。
#   校验脚本见 scripts/audit_models.py
#
# 下面只是**占位示例**，请把你实际要下的仓库地址换进去。
# 各档位需要哪些模型，见 docs/ComfyUI-tiered-deploy-manual.md 对应章节。
