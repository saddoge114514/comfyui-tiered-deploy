# ComfyUI 分档部署手册

> **只想让 AI 帮你装？把 [交给AI的部署指令_AGENT-RUNBOOK.md](交给AI的部署指令_AGENT-RUNBOOK.md) 整份发给它就行，不用自己一步步照做。**

本仓库记录在一台 Windows 机器上部署 ComfyUI 本地出图环境的完整过程，并配套提供部署脚本与配置模板。覆盖范围为**环境搭建、参数控制、ControlNet 姿势约束、人脸二次精修、2K 放大**，即阶段 C。阶段 D（视频生成）仅验证了 Wan2.2 I2V 单条链路，实测 5 秒 480p 耗时 102 秒，尚不构成成熟方案，仅在手册中作为参考记录。

依据显存容量将机器划分为 T1 至 T5 五档，各档给出独立的部署流程、模型清单、启动参数与已知问题。其中仅 T4 档（14–16G 显存）的数据来自实机测量，其余档位为推算或无数据，正文逐条标注。

**本仓库不包含任何提示词。** 不包含人物设定、角色描述、场景描述、生成图片与模型权重。手册中出现的 `prompt.txt` 均为占位符，指向使用者自行准备的文件。

## 使用方法

**方式一，自己照着做：**

1. 执行手册第 1 节的硬件检查脚本，记录显存总量。
2. 按下表确定所属档位。
3. 打开手册对应章节，依「部署流程」顺序执行。

**方式二，整份丢给 AI 执行：** 把 [交给AI的部署指令_AGENT-RUNBOOK.md](交给AI的部署指令_AGENT-RUNBOOK.md) 全文发给 AI，它会按阶段 0→5 顺序执行——每阶段有命令、有验证条件、有失败分支，需要管理员权限的步骤会停下来等你。开场白模板在手册第 10 节。

| 显存容量 | 档位 | 适用情况 |
|---|---|---|
| 核显或无独立显卡 | T1 | 仅可运行 SD1.5 512×768，速度较慢 |
| 6–8G | T2 | 可运行 SDXL，需启用 `--medvram`，不建议开启人脸精修 |
| 10–12G | T3 | 全链路可用，速度一般 |
| 14–16G | T4 | 全链路可用，本手册实测数据来源档位 |
| ≥20G | T5 | 可启用批量生成，速度更快 |

手册地址：[docs/ComfyUI本地出图_分档部署手册_ComfyUI-tiered-deploy-manual.md](docs/ComfyUI本地出图_分档部署手册_ComfyUI-tiered-deploy-manual.md)

## 环境变量

脚本内的路径不写死，统一由环境变量提供。默认值对应本机布局，可自行修改。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `COMFY_ROOT` | `D:/AI` | 安装根目录 |
| `COMFYUI_MODELS` | `$COMFY_ROOT/models` | 模型目录 |
| `COMFY_OUT` | `$COMFY_ROOT/output` | 产物目录 |
| `COMFY_URL` | `http://127.0.0.1:8188` | ComfyUI API 地址 |
| `ARIA2C` | `$COMFY_ROOT/temp/aria2c.exe` | aria2c 可执行文件路径 |

调用示例：

```powershell
python gen.py --pos @C:\my\prompt.txt --neg @C:\my\negative.txt `
  --w 832 --h 1216 --steps 26 --cfg 6.0 --seed 1234 --prefix test
```

参数说明见 [scripts/README.md](scripts/README.md)。

## 两项关键注意事项

**一、文件大小不足以判定模型完整性。** 部署过程中出现过一种情况：七个模型文件下载完毕，文件大小与官方 content-length 完全一致，safetensors 头部可正常解析，且按「头部声明的偏移量 + 8 + 头部长度等于文件大小」逐项核对全部通过，但生成的图片为纯灰色。逐张量检查方差后发现 78% 的权重为零值，成因是下载器预分配产生的空洞。此类损坏只有 sha256 校验可以识别，因此 `audit_models.py` 属必要组件。

**二、ComfyUI 会复用完全相同的执行请求。** 相同的提示词、参数与种子重复提交时，服务端直接返回缓存结果，实际并未重新采样。测量耗时须更换种子。

其余问题汇总于手册第 8 节，共二十余条，均记录了现象与成因。

## 测试环境

- ComfyUI v0.43.0。节点名称与启动参数以该版本为准，升级后可能变化。
- 使用 ComfyUI 便携版自带的 Python 3.13，不依赖系统 Python。
- 操作系统：Windows 11 24H2。
- 实测机型：i7-14700KF、RTX 4080 SUPER 16G、64G 内存。T4 档全部数据来自该机，其余档位为推算。
- 脚本使用标准库与 Pillow，跨平台可行，路径写法需按系统调整。
